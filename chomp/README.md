# Chomp 迷宮追擊 (Python)

經典的迷宮追逐：吃掉整座迷宮的豆子，四隻鬼各有自己的追擊邏輯（紅色直衝、粉色埋伏
你前方四格、青色用紅鬼當鏡像包夾、橘色一靠近就逃回角落）。大力丸能讓鬼變藍，
連吃 200→400→800→1600；迷宮左右相通，中間是鬼屋，每 70／170 顆豆子會掉一次水果。
單一檔案 `chomp.py`，Tkinter 深色介面，只用標準庫，沒有第三方套件。

程式分三層：純邏輯 `ChompGame`（完全不碰 UI，可無視窗測試）、圖形介面 `ChompGUI`、
內建豆子獵人 bot `ChompBot` + 無視窗對打 `run_simulate`。

## 執行

```bash
python3 chomp.py                         # 玩（普通）
python3 chomp.py -d easy                 # 簡單：鬼慢 15%、驚嚇時間長 35%
python3 chomp.py -d hard                 # 困難：鬼快 15%、驚嚇時間短 25%
python3 chomp.py -l 3                    # 從第 3 關開始（鬼更快、驚嚇更短）
python3 chomp.py --lives 5               # 五條命
python3 chomp.py --seed 7                # 固定驚嚇時鬼的亂數轉向（可重現）
python3 chomp.py --no-highscore          # 不讀也不寫 chomp/highscore.json
python3 chomp.py --simulate 60           # 無視窗：內建 bot 打 60 秒並印出結果
python3 chomp.py --text 25               # 無視窗：印出第 25 秒的迷宮 ASCII
python3 chomp.py --selftest              # 跑邏輯測試（231 項）
```

沒有 tkinter 或開不了視窗時，`--simulate`、`--text`、`--selftest` 仍可正常使用。

## 操作

| 按鍵 | 動作 |
| --- | --- |
| 方向鍵 / `W` `A` `S` `D` | 轉向（轉彎會在下一個路口生效，回頭是立即的） |
| `P` | 暫停 |
| `R` / `N` / `F2` | 重新開始 |
| `1` / `2` / `3` | 簡單 / 普通 / 困難（會直接開新的一局） |
| `Esc` | 離開 |

面板最上方是分數、最高分、第幾關、生命（黃色小精靈圖示）、剩餘豆子與目前狀態；
右側是四隻鬼的個性與一句話說明、吃過的水果、目前模式（散開／追擊／驚嚇）與這一階段
還剩幾秒，以及操作說明。畫面上的中文字：開局與每條命開始顯示「準備」、吃到大力丸後
狀態顯示「鬼魂驚嚇中」、清空迷宮顯示「過關！」、被抓住顯示「被抓住了」、
結束顯示「遊戲結束」與分數／關數／時間。

## 玩法與數值

- **迷宮**：21×22 格，205 顆豆子 + 4 顆大力丸，左右鏡像對稱，第 11 列是兩端相通的隧道。
  迷宮刻意做成**沒有任何死路**（每格至少有兩個出口）——單一出口的格子只要被鬼堵住就是必死，
  所以每個正方形的豆子區都是環狀的；`--selftest` 會直接驗證這件事。
- **速度**：以每秒 10 格為基準。第 1 關小精靈 0.80、鬼 0.75；第 2–4 關 0.90／0.85；
  第 5–20 關 1.00／0.95；第 21 關之後 0.90／0.95（鬼終於比你快）。
  驚嚇中 0.50～0.60、**隧道裡只有 0.40～0.50**（所以隧道是甩掉鬼的地方），
  眼睛回鬼屋 1.60、出鬼屋 0.55。難度係數只乘在鬼身上：簡單 ×0.85、困難 ×1.15。
- **鬼的目標格**（`ghost_target`，全部是原版公式）：
  `blinky` 就是你所在的格子；`pinky` 是你前方四格，**面朝上時會多偏左四格**
  （原版的溢位 bug，這裡刻意保留下來）；`inky` 是把「你前方兩格」對紅鬼做點對稱再乘二；
  `clyde` 距離你八格以上時直衝你，八格以內就掉頭回自己的角落。
- **鬼的轉向**：每到一個路口，從「不能回頭」的可行方向中挑離目標最近的一個，
  平手時依上→左→下→右的順序；散開期各走各的角落，驚嚇期改成亂數選擇。
  鬼屋門口兩側的兩格是**禁止向上**的（驚嚇時不受限）。
- **散開／追擊排程**（`MODE_SCHEDULE`）：7 秒散開、20 秒追擊、7 秒、20 秒、5 秒、20 秒、
  5 秒、之後永遠追擊。切換的瞬間所有在外的鬼都會立刻回頭，驚嚇期間排程暫停。
- **大力丸**：第 1 關 7 秒、第 2 關 6 秒……之後依 `FRIGHT_SECONDS` 縮短（最低 1 秒）；
  同一顆大力丸內連吃四隻鬼是 200 / 400 / 800 / 1600，被吃掉時遊戲會凍結 0.7 秒顯示分數，
  鬼變成眼睛高速衝回鬼屋，0.6 秒後重新出發。
- **鬼屋放行**：粉鬼一開始就出來，青鬼吃到 30 顆、橘鬼吃到 60 顆才放行；
  如果 4 秒都沒吃到豆子，鬼屋也會清空（`NO_DOT_RELEASE`）。
- **水果**：吃到第 70 與第 170 顆豆子時，在鬼屋前（小精靈起點）出現 9.5 秒，
  依關數是櫻桃 100、草莓 300、橘子 500、蘋果 700、甜瓜 1000、香蕉 2000、鳳梨 3000、鑰匙 5000。
- **其他**：豆子 10 分、大力丸 50 分、滿 10000 分多一條命（只給一次）、三條命、
  開局「準備」2.2 秒、被抓動畫 1.8 秒、過關閃爍 2.4 秒、碰撞判定距離 0.5 格。

## 特色

- 固定時間步：`step()` 就是 1/60 秒，所有速度以「格／秒」為單位，邏輯與畫面更新率無關
- 每個動作都回傳事件（`dot`、`pellet`、`fright`、`ghost:400`、`fruit:300`、`death`、
  `levelclear`、`level:2`、`leave:inky`、`mode:chase`、`gameover`…），介面只負責把事件翻成特效
- **移動模型**：每個角色記住「在第幾格、往哪個方向、走了多少」，位置 = 格 + 0.5 + 方向 × 進度，
  所以轉彎只可能發生在格子中心、回頭是精確的（格往前移一格、進度取 1−進度，位置完全不變），
  隧道穿越直接把 x 取模。這些都能在沒有視窗的情況下斷言。
- **bot 用「路程」而不是直線距離判斷危險**：從每隻鬼（再往前推兩格，因為鬼不能回頭）
  做多源 BFS，得到「哪些格子幾步內會被踩到」；再從自己 BFS 出所有豆子的路線，
  分數 = 豆子價值 − 路程 − 危險路段罰分。被逼到 3 步內就切換成逃跑模式：
  優先挑「鬼最晚到」的格子，並用安全空間啟發式避免跑進死角（隧道因為鬼會減速，危險度打折）。
  實測 60 秒能吃掉 209 顆裡的 160 顆左右，穩定活過一分鐘。
- **Canvas 分層**：牆與外框畫一次（tag `maze`），豆子畫一次後**吃掉時只刪那一顆**
  （tag `dot`，用座標查 item id）；只有小精靈、四隻鬼、HUD 與特效每格重建（約 40 個物件），
  所以每一格的成本跟盤面剩多少豆子無關
- macOS 鍵盤處理：`KeyRelease` 後延遲 50 ms 才忘記按鍵（避開自動重複的交錯），
  所有按鍵都走這條路；視窗失焦時清空按鍵（子元件的焦點事件會被忽略）

## 結構

`chomp.py`

- `ChompGame` — 純邏輯與規則：`start`、`step`、`set_pac_dir`、`_step_mode`、`_step_pac`、
  `_eat_at`、`_step_ghosts`、`_choose_ghost_dir`、`ghost_target`、`_house_step`、
  `_collisions`、`_after_death`、`_next_level`、`_step_fruit`、`is_frightened`、
  `ghost_speed`、`pac_speed`、`ascii_frame`、`hud_text`
- `Mover` — 「格 + 方向 + 進度」的移動模型：`advance`、`reverse`、`pos`
- `ChompGUI` — Tkinter 介面：`_draw_maze`（牆與外框，只畫一次）、`_draw_dots`、
  `_draw`（小精靈、鬼、水果、彈分、HUD、覆蓋層）、`_handle_events`、`_remove_dot`
- `ChompBot` / `run_simulate` — 無視窗對打，供 `--simulate`、`--text` 與測試使用
- `load_highscore` / `save_highscore` — 最高分存讀檔（只增不減）

`--selftest` 的 231 項檢查涵蓋：迷宮表的尺寸與對稱、邊界、隧道、四顆大力丸的位置、
鬼屋與門、**每一顆豆子都走得到**、**沒有任何死路**、
開場狀態與「準備」倒數、小精靈的速度與牆壁阻擋、直角轉彎在下個路口生效、
回頭不位移、隧道穿越、吃豆子與大力丸的分數與計數、清空迷宮→下一關→盤面重填、
四隻鬼的目標格公式（含粉鬼向上的溢位、青鬼的鏡像、橘鬼的八格切換）、
散開／追擊排程與切換時的回頭、不回頭與平手順序、禁止向上的兩格、
驚嚇期亂數轉向、鬼屋放行門檻 0/30/60 與 4 秒強制放行、出鬼屋與眼睛回家復活、
速度表與難度係數、驚嚇時間、連吃 200/400/800/1600 與上限、
被抓住→扣命→歸位、最後一條命→結束、眼睛無害、同格與跨格中段的碰撞、
水果的兩個門檻與過期、10000 分多一條命、暫停、ASCII 畫面格式、
bot 在 60 秒與 150 秒的表現與「剩餘豆子 = 總數 − 已吃」的不變式、
**嘴巴朝向對照表**（Tk 的弧角是從 3 點鐘逆時針，90 度是正上方，寫反就會往上走卻朝下咬）、
以及最高分存讀檔。

介面另外用一個 59 項的無視窗檢查驗證過（建視窗、真實 Tk 按鍵路由與 `<F2>`、失焦清鍵、
八個轉向鍵、暫停／重來／難度切換、吃掉豆子時畫布上那一顆真的被刪掉、
**連按重來不會在畫布上累積豆子**、4000 幅的 bot 實跑不暴增物件、各種覆蓋層與特效、
關窗後殘留的按鍵事件不會炸掉），
並在真實視窗上截圖確認過排版與配色。
