# 霓虹貪食蛇 Neon Serpent (Python)

霓虹風格的貪食蛇：**連擊倍率**、**六種果實／道具**、畫面震動與粒子、即時合成的音效，
加上三種模式（經典／穿牆／限時）與分模式最高分存檔。

單一檔案 `snake.py`，pygame 介面。所有圖形都在執行時用程式畫出來、音效則由 numpy
即時合成——沒有任何圖片或音檔素材。

## 需要什麼

- Python 3.10+
- `pygame` 2.x（必要）
- `numpy`（用來合成音效；沒安裝會自動靜音，遊戲照常可玩）

```bash
python3 -m pip install pygame numpy
```

## 執行

```bash
python3 snake.py                     # 開選單
python3 snake.py --play              # 跳過選單，直接開始預設模式
python3 snake.py --play --mode wrap  # 直接開始穿牆模式
python3 snake.py --seed 7            # 固定果實順序（可重現）
python3 snake.py --mute              # 靜音啟動
python3 snake.py --no-highscore      # 不讀也不寫 highscore.json
python3 snake.py --selftest          # 無視窗邏輯測試（109 項）
python3 snake.py --text 2            # 無視窗跑 2 秒，印出 ASCII 盤面
```

## 操作

| 按鍵 | 功能 |
|---|---|
| `↑ ↓ ← →` / `WASD` | 轉向（最多緩衝兩次轉向，轉彎手感更順） |
| `Space` / `P` / `Esc` | 暫停；再按一次繼續 |
| `R` | 立刻重來 |
| `Q` | 回選單 |
| `M` | 音效開關 |
| 選單 `↑↓` + `Enter` | 選模式並開始 |
| `1` / `2` / `3` | 直接開始經典／穿牆／限時 |
| 滑鼠點卡片 | 直接開始該模式 |

## 三種模式

| 模式 | 規則 |
|---|---|
| 經典 CLASSIC | 30×20 棋盤，撞牆或咬到自己就結束；每吃一顆果實加速 |
| 穿牆 WRAP | 邊界會穿到對面，適合練習極限長度 |
| 限時 SPRINT | 90 秒衝分，初始與最高速度都比經典快 |

速度是每格間隔：經典從 0.140 秒降到 0.060 秒，穿牆 0.130→0.055，限時 0.125→0.055，
每吃一顆果實，間隔就乘上 0.985 左右的加速係數（依模式略有不同）。

## 果實與道具

| 圖示 | 名稱 | 分數 | 效果 |
|---|---|---|---|
| 紅蘋果 | 蘋果 | +10 × 連擊 | 蛇變長、速度上升 |
| 金蘋果 | 金蘋果 | +50 × 連擊 | 分數大補 |
| 紫紅毒果 | 毒果 | −30 | 扣分（最低到 0），並中斷連擊 |
| 綠雪花 | 減速 | +15 | 7 秒內移動變慢，方便調整 |
| 藍色 ×2 | 雙倍 | +15 | 8 秒內得分翻倍（會與連擊相乘） |
| 橘色螺圈 | 縮短 | +20 | 尾巴立刻縮短，最多 5 節（至少保留 3 節） |

每吃 4 顆果實（蘋果或金蘋果）會生出一顆特殊果實，場上最多同時 3 顆；
道具在盤面上 7–9 秒後消失。果實不會生在蛇身上或另一顆果實的位置。

## 計分與連擊

- 在 3.2 秒內連續吃到下一顆果實就會累積連擊，倍率 1→8。
- 單顆得分 = 果實基本分 × 連擊倍率（雙倍期間再 ×2）；吃到毒果會中斷連擊並扣 30 分。
- 限時模式剩餘 15 秒時倒數會轉紅，剩 10 秒內開始閃爍。

## 程式架構

`snake.py` 分三層，邏輯層完全不碰 pygame：

- `SnakeGame`：純格線邏輯。`step()` 固定推進 1/60 秒並回傳事件串流
  （`eat`／`power`／`poison`／`die`／`combo_end`…），所以整場遊戲可以在無視窗下
  重播與測試。
- `Renderer`：棋盤、蛇身光暈、果實圖示、粒子、HUD、選單與各種覆蓋面板；
  全部用 `pygame.draw` 程式繪製，字型用系統的 PingFang TC（中文）與 Avenir Next（數字）。
- `GameApp`：pygame 主迴圈、輸入緩衝、狀態機（menu／play／pause／dead）、
  音效播放、畫面震動與定格特效、高分存取。

視覺小細節：蛇身是逐節顏色漸層的「霓虹燈管」，頭部有眼睛與吐信；吃到東西有
粒子爆散、加號浮字、震動與短暫閃光；選單卡片會浮起，滑鼠移過時邊框會亮起來。

## 無視窗模式與測試

`--text SECONDS` 用固定步進模擬指定秒數後印出 ASCII 盤面（蛇頭 `@`、蛇身 `o`、
蘋果 `*`、金蘋果 `G`、減速 `S`、雙倍 `D`、縮短 `T`、毒果 `P`），方便在沒有視窗的
環境檢查邏輯。

`--selftest` 有 109 項檢查：移動與轉向緩衝、成長、吃果實計分、連擊窗口與上限、
毒果扣分、所有道具效果、穿牆、撞牆／自撞／限時死亡、果實不重疊生成、
特殊果實數量上限、高分讀寫的原子性與容錯、決定性種子等。

## 疑難排解

macOS 上若視窗裡的中文變成整條純色方塊（但在無視窗截圖中正常），原因是 SDL 的
顯示表面帶有 alpha 通道，而背景畫布透明像素的 RGB 被直接複製到畫面。1.0.1 起改為
先畫到 24-bit 不透明畫布 `frame`，再整張貼到視窗，已修正此問題。

## 高分

每個模式各存一筆最高分到同資料夾的 `highscore.json`（分數、長度、最高連擊、
存活時間）。寫檔採先寫暫存檔再 `os.replace`，壞檔會自動忽略。此檔案已列入
`.gitignore`；`--no-highscore` 可完全停用。
