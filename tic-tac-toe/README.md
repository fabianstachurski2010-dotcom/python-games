# Tic-Tac-Toe (Python)

井字遊戲：你（X）對上完美的 minimax 電腦，或跟朋友雙人對戰，或對上隨機亂下的電腦。
單一檔案 `tic_tac_toe.py`，Tkinter 深色介面，不需要任何第三方套件。

程式分三層：純邏輯與 AI `TicTacToe`、圖形介面 `TicTacToeGUI`、終端機介面 `run_text`。

## 執行

```bash
python3 tic_tac_toe.py               # 玩（預設無敵電腦）
python3 tic_tac_toe.py -m easy       # 電腦隨機亂下
python3 tic_tac_toe.py -m two        # 雙人對戰
python3 tic_tac_toe.py --seed 3      # 固定簡單電腦的隨機
python3 tic_tac_toe.py --text        # 終端機模式
python3 tic_tac_toe.py --selftest    # 跑邏輯測試（28 項）
```

沒安裝 tkinter 時會自動退回終端機模式；有 tkinter 但開不了視窗則提示改用 `--text`。

## 操作

| 操作 | 動作 |
| --- | --- |
| 點格子 | 下在該格 |
| `1`–`9` 鍵 | 下在對應格（1 = 左上、9 = 右下） |
| `M` | 循環切換對手：電腦（無敵）→ 電腦（簡單）→ 雙人 |
| `R`、`N` 或 `Enter` / `F2` | 新的一局 |
| `Esc` | 離開 |

介面上方左邊是狀態（「輪到你」「電腦思考中」「你贏了／你輸了／平手」，
雙人模式是「輪到 X」），右邊是比分「你 0　電腦 0　平 0」（雙人模式是「X 0　O 0　平 0」）。
視窗標題會顯示目前對手，例如「電腦（無敵）」。

介面沒有選單列：切換對手用 `M` 鍵，而且**切換對手時計分板會歸零**（換對手等於重新開始）。
棋盤格子是 `tk.Label`，X 用藍色 `#5ea1ff`、O 用紅色 `#ff6b6b`，贏的那條連線用深綠底色
`#3f5f3a` 標出。電腦思考有 180 ms 的延遲（`AI_DELAY_MS`），期間狀態顯示「電腦思考中」。

終端機模式用 `1`–`9` 輸入，`n` 新局、`q` 離開、`?` 說明。

## 特色

- 預設對手是全盤搜尋的完美玩家（negamax + 以棋盤狀態記憶化），**不可能被擊敗**，
  最好的結果就是和局
- 有立即獲勝的點一定先拿（`best_move_for` 會先掃一次立即勝）；多個走法一樣好時，
  偏好順序是中心 → 角落 → 邊，所以下起來像人而不像機器
- 計分板累計「你 / 電腦 / 平手」，雙人模式改成記 X / O

## 為什麼它真的無敵

`--selftest` 用暴力枚舉**所有人類策略**（人類每一步的所有可能走法，電腦一律以最佳走法
回應）來驗證，而不只是跑幾個範例：

```
every human strategy: AI wins 368, draws 153, human wins 0
```

人類取勝的局數是 0，這就是「無敵」的定義。整個搜尋因為以棋盤狀態做記憶化
（棋盤只有 3^9 種狀態），跑完只要半秒左右。

## 結構

`tic_tac_toe.py`

- `TicTacToe` — 棋盤、勝負判定與 AI，完全不碰 UI。查詢類方法都是 staticmethod 且吃任意
  序列，所以測試可以直接餵 tuple；`_solve` 是加上 `lru_cache` 的 negamax 核心
- `TicTacToeGUI` — Tkinter 介面：Label 格子、即時狀態與比分、`M` 切換模式
- `render_text` / `run_text` — 終端機介面
- `perfect_ai_record()` — 暴力枚舉所有人類策略的證明函式，供 `--selftest` 使用

評分採「結果制」negamax：對輪到的一方來說 +1 是贏、0 是和、-1 是輸，再搭配
`best_move_for` 的立即獲勝檢查與偏好順序補足「像人」的感覺。

`--selftest` 的 28 項檢查涵蓋：八條連線的勝負判定、和局、九步填滿棋盤、合法／佔用／
越界落子被拒、立即取勝、唯一活路的阻擋、開局下中心、結束後不再回傳走法、無敵性
（暴力枚舉）、隨機 AI 落子合法、雙人模式不會自動幫對手走且會輪替、AI 會等自己的回合、
棋盤複製互相獨立，以及狀態文字正確。
